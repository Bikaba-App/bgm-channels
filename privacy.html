Privacy Policy

Last updated: 2026-10-25

What this application is

BGM Channel Manager is a private tool used only by its operator to manage the operator's own YouTube channels. It is not offered to the public.

Data we access

With the operator's authorization through Google OAuth, the application accesses:

  • YouTube channel and video information (titles, descriptions, thumbnails, live broadcast settings) of the operator's channels
  • YouTube Analytics and Reporting data (views, watch time, thumbnail impressions and click-through rate) of the operator's channels

How the data is used

The data is used only to schedule and manage live streams, update video metadata and thumbnails, and evaluate channel performance. It is not used for advertising and is not sold or shared with third parties.

Storage

OAuth tokens and statistics are stored only on the operator's own computer. No data is stored on external servers controlled by this application.

YouTube API Services

This application uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account third-party connections page. Locally stored tokens and data are then deleted.
